Shortify v0.5.2 Update

This patch fixes the packaged EXE startup error: No module named ui.

How to apply:
1. Extract Shortify_v0.5.2.zip.
2. Open the extracted Shortify folder.
3. Copy everything inside it.
4. Paste into C:\Users\User\Shortify.
5. Choose Replace files.
6. Run: .\run_dev.bat
7. Build: .\build.bat
8. Test EXE: .\dist\Shortify\Shortify.exe
