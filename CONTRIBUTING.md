# Contributing to Shortify

Shortify is an open-source, local-first desktop app for creators.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test locally.
5. Open a pull request.

## Development rules

- Keep the app local-first.
- Do not add forced login.
- Do not upload user videos or API keys anywhere.
- Store user settings locally.
- Keep code readable and beginner-friendly.

## Good first issues

- Improve UI layout.
- Add better error messages.
- Add model presets.
- Improve clip scoring prompts.
- Add installer improvements.
